# María del Mar Blanquería

Sitio web de e-commerce MVP para un emprendimiento de blanquería. Desarrollado con HTML, CSS y JavaScript puro — sin frameworks ni dependencias.

🌐 **Live:** [maria-del-mar-blanqueria.netlify.app](https://maria-del-mar-blanqueria.netlify.app)

---

## Estructura

```
├── index.html
├── css/
│   └── styles.css
├── js/
│   ├── main.js
│   └── cart.js
└── assets/
    ├── logo.png
    └── logo-transparent.png
```

---

## Correr en local

```bash
git clone https://github.com/NicoPavoni/maria-del-mar-blanqueria.git
cd maria-del-mar-blanqueria
```

Abrí `index.html` con **Live Server** en VS Code.
